# App UX extras

Phone-oriented utilities. Full how-to: [../user/guide.md](../user/guide.md).

## Status metrics

Server → **Status**: session + uptime + listen; Mode chips (Auth, RO, Web, CORS, Cache); activity; transfers; device (battery, temp, RAM, …). Restart banner when bind-critical settings changed while running.

## Folder picker

**Quick Access**: Internal, SD, Downloads, Gallery/Pictures, Documents, Movies, Music (when storage allows). **Browse** for the rest. Folders only; SAF for SD/document trees — pick the SD **root** then Select if the app asks, so writes work.

## Logs

Live pause, saved sessions, search, filters (level / method / status), copy, export/share, clear, delete sessions. Optional web-client admin view (**Admin** user + setting on).

## Notifications

| Kind | Where |
|------|--------|
| System ongoing | While server runs; stop one/all |
| In-app inbox | Bell on server list (refresh, links, rate, dismiss). TV: mostly blocking dialogs |

## Onboarding

First launch: welcome → permissions one-by-one (storage → notifications → battery; Skip later) → name/port → folder → Ready → Open → Start. TV wording is slightly shorter.

## Home / Connect

After start: address, **Connect** sheet (QR, Copy, Share, open). Share chip on Home. Restart-needed banner when applicable.

## Other

Add-server screen (name/port/password/folder), About sheet, Feedback / Help / Ask AI, Wi‑Fi address refresh + auto-restart, multi-server play/stop on cards, Client UI labels (WebDavFS / Old Modern / Old / No JS), Pro hidden-files options.
