# Reference — optional full-repo docs

This publishable tree (`docs_ai/`) is **self-contained** for end users and for most developer / AI questions.

If you have the **full application source repository**, it may also include a sibling `docs/` folder with longer essays. Those files are optional; paths below are not required to publish `docs_ai/` alone.

| Path in full repo | Topic |
|-------------------|--------|
| `docs/HELP.md` | Older end-user help (prefer [../user/guide.md](../user/guide.md) here) |
| `docs/README.md` | Settings / architecture essay |
| `docs/SSL_CERTIFICATES.md` | Full TLS design |
| `docs/PLAY_FGS_SPECIAL_USE.md` | Long Play Console `specialUse` draft |
| `docs/ACME_DNS_NIC_UA.md` | Example DNS-01 walkthrough |
| `docs/platform-api.md` | Embedded JS `window.WD` |
| `docs/filemanager-api.md` | FileManager JS API |
| `client/README.md` | Web UI build / deploy |
